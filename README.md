# USDA FSIS Recall Data Feed

Automated public data feed for USDA FSIS (Food Safety and Inspection Service) meat, poultry, and processed egg recalls.

### Endpoints
* **Raw JSON**: `https://raw.githubusercontent.com/eowusu/usda-recall-feed/main/usda_recalls.json`

### Automated Sync
Updates every 3 hours via GitHub Actions workflow.
